My Projects:

C-Unplugged Application-

A CLI based simple music management application, written completely in C. App allowed users to manage a song library, and perform basic functions like creating new playlists, navigating playlists, liking songs, managing queue,etc. It also logged command history across different sessions.
I built it as an assignment in Computer Programming course in Sem-1.
If I have to do it now, I will make it in C++, as it would help in simpler code and better memory management as memory leaks were pretty hard to manage in C.

Twixt Game-

A CLI based C implementation of the connections board game known as Twixt. The program handled the core game logic, displayed the game board, ran the pegs placement rules check, and had the game winning logic to output who won.
This program was built as the Course Project for the COmputer Programming course in Sem-1.
If I had to do it now, I would 100% do it in C++, as C++ has the standard libraries for easy graph traversals.It was a nightmare to implement in C. Also, I would optimize my DFS traversal approach as I did not know about it then, and had implemented a custom traversal of mine which was highly inefficient.
Making the game in CLI was a technological tradeoff we took to simplify the design for a reliable C project.

NoQ - Canteen Ordering System

THis was an application to order food from canteens of our campus, which could be placed from anywhere. It was a team project and we built it for the HackIIIT event at our campus, organised by OSDG. It was meant to be solving the problem of waiting in long queues for our orders. If we had enough time, we would have polished the UI/UX. It was actually not 100% functionable till submission deadline. We would also integrate the payment method as we couldn't implement it then. We also couldn't implement real time update functionality, which was a pretty huge task to be completed in a single day. Still it helped us learn a lot.
